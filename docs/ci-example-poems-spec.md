# 词牌例词数据规格（给数据同学）

## 背景 / 目标

编辑器在选择词牌/变体时展示的是**平仄格律网格**（"中 仄 平 平…"），但缺少**真实例词**对照。
本规格定义一份「变体 → 例词」数据，用途有四：

1. **用户对照**：选中某变体时，把例词逐字叠在格律格子上给用户看（韵脚高亮）。
2. **修复结构**：例词自带**句读（分句）**和**上/下阕**信息，正好能校正词谱当前的分段/分行 bug（换头句错位、摊破长行等）——详见文末「附带收益」。
3. **修复标点**：例词**保留原文标点**（逗、句、问、叹…），编辑器行尾标点直接照搬，根治「密韵词满屏句号」的问题（当前编辑器对定风波这类几乎句句押韵的词，凡韵脚一律标句号）——详见文末「附带收益」。
4. **修复导出排版**：例词标点天然定义**句群**（逗号相连的句同处一行、句号收行），导出图片按此分行，根治「密韵词逐句断行、2 字短句独占一行」的零碎排版——详见文末「附带收益」。

**粒度**：每个变体一首（约 2475 个变体），键为现有变体 `id`（如 `定风波-苏轼体`）。
每个变体都有对应作者（`author` 字段），例词应取**该作者据以定谱的那一首**（钦定词谱正体/变体所引例词），而非随便一首同调作品。

---

## 数据格式

每个变体一条记录，整体为一个 JSON 对象 `{ [variantId]: ExamplePoem }`：

```jsonc
{
  "定风波-苏轼体": {
    "id": "定风波-苏轼体",
    "author": "苏轼",
    "title": "莫听穿林打叶声",        // 词题或首句，用于展示标题
    "source": "全宋词",              // 出处/数据来源，便于追溯
    "sections": [
      // 上阕：每个数组元素 = 一「句」，= 汉字 + 该句尾的原文标点
      ["莫听穿林打叶声，", "何妨吟啸且徐行。", "竹杖芒鞋轻胜马，", "谁怕？", "一蓑烟雨任平生。"],
      // 下阕
      ["料峭春风吹酒醒，", "微冷，", "山头斜照却相迎。", "回首向来萧瑟处，", "归去，", "也无风雨也无晴。"]
    ]
  }
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✔ | 变体 id，须与词谱 bundle 里的变体 id 完全一致 |
| `author` | ✔ | 作者，须与词谱该变体的 `author` 一致（用于核对取词是否正确） |
| `title` | ✔ | 词题；无题则填首句 |
| `source` | ✔ | 出处（全宋词 / 钦定词谱 / 花间集 …），便于追溯校对 |
| `sections` | ✔ | 二维数组：`sections[阕][句]`。**双调两个阕**，单调一个阕。每个元素是一「句」：**汉字 + 该句尾的原文标点** |

### 关键约束（务必遵守，否则无法对齐格律 / 无法还原标点）

1. **汉字 + 句尾标点**：每个元素 = 该句的汉字，后接原文该句末尾的**一个**标点（`，` `。` `？` `！` `、` `；`）。
   - 句**中间**不要留标点（一句一元素，中间停顿就拆成两个元素）。
   - 叠字/异体字按原文；生僻字用原字，不要用拼音或缺字符号。
   - 标点是**行尾标点展示**的唯一依据，务必照原文，别统一成句号。
2. **一个数组元素 = 一「句」**：以钦定词谱的句读为准。
   - 例：定风波「谁怕？」「微冷，」「归去，」都是独立的 2 字短句，各占一个元素。
3. **阕的划分要对**：`sections[0]` = 上阕（前段），`sections[1]` = 下阕（后段）。
   - **换头（过片）**那一句归**下阕第一句**，别并进上阕。
4. **字数要对齐**：`sections` 全部**汉字**数（**不计标点**）== 该变体词谱字数（sketch 里的「双调N字」）。
5. **句数要对齐**：`sections[0].length` == sketch「前段X句」；`sections[1].length` == sketch「后段Y句」。

> 4、5 两条我方会在导入时自动校验；对不上的会退回清单请数据侧核对。

## 已填样例（可直接作为格式基准）

`定风波-苏轼体`（双调六十二字，前段五句、后段六句）：

| 阕 | 句 | 例词（含原文标点） | 汉字数 |
|---|---|---|---|
| 上 | 1 | 莫听穿林打叶声， | 7 |
| 上 | 2 | 何妨吟啸且徐行。 | 7 |
| 上 | 3 | 竹杖芒鞋轻胜马， | 7 |
| 上 | 4 | 谁怕？ | 2 |
| 上 | 5 | 一蓑烟雨任平生。 | 7 |
| 下 | 1 | 料峭春风吹酒醒， | 7 |
| 下 | 2 | 微冷， | 2 |

注意标点不是一律句号：句中停顿用「，」，句末/韵段收束用「。」，反问用「？」——这正是当前编辑器缺失、需靠例词补齐的信息。

## 我方导入时的校验规则

- **硬校验（不过就退回核对）**
  - C1 每句 = 汉字串 + 至多一个句尾标点；句中无标点
  - C2 总汉字数（不计标点）== 词谱字数
  - C3 上/下阕句数 == sketch 前段/后段句数
  - C4 每句汉字数 == 对应格律行的格子数（对齐的关键）
- **软校验（仅告警，人工抽检）**
  - C5 定调格子（必平 P / 必仄 Z）处，例词该字的实际平仄应一致（多音字/拗救会告警，正常）
  - C6 韵脚句末字应实际押韵

## 落地方案（我方负责）

1. **存储**：新增 `packages/core/poem-parser/data/ci-examples-bundle.json`（+ `.gz`），
   由 vite 在构建时 copy 到 `apps/web/public/data/`（与现有 bundle 同机制，gitignore 产物）。
2. **加载**：新增 `loadCiExamples(): Record<variantId, ExamplePoem>`，与 `loadCiBundle` 并列。
3. **UI**：在词牌/变体预览面板（当前展示格律网格的地方），选中变体时把例词字逐格叠在平仄格子上；
   韵脚字标红，短句自动断行与格律一致。加一个「显示例词」开关，默认开。
4. **附带修复（结构）**：用例词的句读/阕结构，把词谱 bundle 的分行/分段**重排为权威结构**
   （只重新分组，不改任何字的平仄），一次性根治剩余 ~199 个摊破/叠韵词牌的结构 bug，并复核前两批已修的 525 个。
5. **附带修复（标点）**：编辑器行尾标点改为**照搬例词原文标点**，替换掉现在「凡韵脚一律句号」的规则
   （`packages/apps/web/src/components/composer/utils.ts` 的 `linePunctuation`），根治密韵词满屏句号。
   律诗/绝句无例词时回退到原规则（韵脚→句号），保持现状正确。
6. **附带修复（导出排版）**：导出图片的可视分行改为**按例词句群分组**（逗号相连的句并入一行、句号收行），
   替换掉现在「逢韵即断行」的 `visualLineGroups = rhymeGroups`
   （`packages/apps/web/src/hooks/useEditorPattern.ts` + `packages/core/layout-core/src/text.ts` 的
   `createPoemLayoutDocument`），根治密韵词逐句断行、2 字短句独占一行的零碎排版。

## 附带收益（为什么这份数据值得做全）

这份例词是**同一份数据、四处收益**：

1. **例词对照**（用户功能）；
2. **词谱结构修复**：剩余 199 个结构 bug（摊破/叠韵/减字类，如酒泉子、河传、瑞鹤仙、蔡伸体）没法自动修，
   就是因为**无法在长行内部推断句读切分点**；例词一到，句读即确定，全部精确修好并自动校验；
3. **标点修复**：密韵词（定风波、采桑子、忆江南…）当前「凡韵脚一律句号」，满屏句号；
   例词原文标点一到，行尾标点照搬即准；
4. **导出排版修复**：密韵词导出时几乎句句押韵 → 逢韵即断行 → 逐句成行、2 字短句独占一行，观感零碎；
   例词句群一到，按句群分行即整。

> 收益 2/3/4 同根：现在这套「逢韵即断/即句号」的启发式不懂词的自然句读，密韵词全线崩。例词一份数据全解。

所以这份数据越全，收益越大——建议做全 2475 变体。
